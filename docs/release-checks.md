# 0.3.0 배포 검증

## 기능 검증

- 로컬 테스트 223개 통과. 실제 MCP stdio 초기화·도구 호출, HTTP Origin 검사, 독립 wheel 로딩 포함.
- 20,000개 합성 키워드를 모의 HTTP로 등록 100개씩·입찰가 수정 200개씩 빠짐없이 전송.
- 잘못된 파일 경로·계정·해시·offset·확인값·공식 한도 초과 차단, 오류·시간초과 뒤 자동 재전송 차단.
- 저장된 20,000행을 부분 조회로 완전히 복원하고 대량 실패 응답의 원문 보존 확인.
- 공식 명세 원문 체크섬 보존. 실제 광고 API 변경은 검증에 사용하지 않음.

## 비밀정보 점검

Gitleaks 8.30.1의 redacted 검사로 현재 배포 폴더, 전체 Git 이력, GitHub Actions 로그, wheel·소스 배포 압축파일을 확인했으며 비밀정보 노출을 발견하지 못했습니다. 설정 예시는 `YOUR_*` placeholder이고 테스트 자격증명은 합성 값입니다. 실제 환경변수 파일·개인 클라이언트 설정·광고 결과 파일은 배포 대상에 포함하지 않습니다.

기존 Hermes 설정에서 확인한 관련 자격증명은 모두 1Password 참조였고, 로컬 평문 키 후보는 없었습니다. Vault를 열거나 실제 키를 출력하지 않았으므로, Vault 내부 키 원문과의 정확한 문자열 대조까지 수행한 결과는 아닙니다. 자동 탐지가 모든 종류의 비밀정보 부재를 증명하지는 않습니다.

각 사용자 키는 자신의 로컬 클라이언트 `env`에 입력합니다. 이미 추적되는 예시 원본에 실제 키를 넣으면 `.gitignore`가 보호하지 못하므로 개인 설정 파일을 사용합니다. 이 문서는 해당 배포 시점의 검증 기록이며 이후 사용자가 수정·업로드한 파일까지 보장하지 않습니다.
