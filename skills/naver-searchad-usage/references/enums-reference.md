# enum과 한도

이 문서에 캠페인 코드·입찰가 범위·자동입찰 전략을 고정해서 복사하지 않습니다. 광고 상품, operation, 계정별 지원 범위가 다를 수 있으므로 **`get_operation_schema`가 제공하는 현재 스키마와 공식 설명**을 확인합니다.

1. 실행할 operation을 선택하고 스키마를 조회합니다.
2. 각 필드의 `type`, `required`, `enum`, 범위와 설명을 확인합니다.
3. 사용자 표현을 확인된 API 코드에 대응합니다. 문서에 없는 코드는 추측하지 않습니다.
4. 현재 상태가 필요하면 실제 조회 operation을 GET으로 실행합니다. 스키마 조회는 광고 계정 상태를 반환하지 않습니다.

공식 명세에 enum이나 업무 제약이 완전히 표현되지 않을 수 있습니다. 스키마에 제한이 없다고 모든 값이 유효한 것은 아닙니다. 반환된 오류와 최신 공식 설명을 함께 확인하고 불확실한 값으로 변경 요청을 시험하지 마세요.

`showDetail` 같은 정수형 매개변수는 해당 스키마가 정수를 요구하면 JSON 숫자로 전달합니다. 배열·문자열·boolean도 마찬가지로 필드별 타입을 지킵니다. 한 API의 필드를 다른 API에 그대로 적용하지 않습니다.
